Three steps: get a key, read, then open a position. Each step shows the SDK call and the raw request.

## 1. Get an API key

Create a key in the [Totalis app](https://totalis-hip4.vercel.app/account/api-keys), under Account,
then API keys, with **Personal account** selected. Name it, pick its scopes, and choose an expiry. The
app asks your Totalis wallet to approve that exact request with a signature, then shows the key.

<Warning>
Copy the key when it is shown. It is displayed once and cannot be retrieved later.
</Warning>

To open positions, select the taker scopes from
[Recommended scope sets](/hyperliquid/authentication#recommended-scope-sets). For reads only,
`identity:read` and `account:read` are enough.

```bash
export TOTALIS_API_KEY="ttk_v1_prd_..."
```

To open positions from code you also need your wallet's key, which signs each trade. Export it as
described in [Export your wallet key](/hyperliquid/authentication#export-your-wallet-key), and read
the known limitation there first.

```bash
export TOTALIS_WALLET_KEY="0x..."
```

## 2. Make your first read

Install the SDK if you have access (see [TypeScript SDK](/hyperliquid/sdk#access-and-install)).
Without it, every call also works as a plain HTTP request.

Market reads need no key. Your identity read confirms the key works:

<CodeGroup>
```ts SDK
import { createClient, unwrap } from "@totalistrading/hip4-client";

const client = createClient("production", { accessToken: process.env.TOTALIS_API_KEY });

const { items } = unwrap(await client.GET("/v1/markets", { params: { query: { limit: 3 } } }));
console.log(items.map((market) => `${market.outcome_id} ${market.title}`));

const me = unwrap(await client.GET("/v1/me"));
console.log(me.wallet); // your Totalis wallet
```

```bash curl
curl "https://hip4-api.totalis.trade/v1/markets?limit=3"

curl https://hip4-api.totalis.trade/v1/me \
  -H "Authorization: Bearer $TOTALIS_API_KEY"
```
</CodeGroup>

The market list, trimmed to the main fields:

```json
{
  "items": [
    {
      "outcome_id": "1209",
      "title": "HYPE touches 100 by 20261001-0000",
      "state": "ACTIVE",
      "category": "Crypto",
      "sides": [
        { "side": "YES", "coin": "#12090" },
        { "side": "NO", "coin": "#12091" }
      ],
      "dates": { "observation_ends_at": "1790812800", "market_class": "PRICE_TOUCH" }
    }
  ],
  "catalog_generation": "6437",
  "next_cursor": "eyJnIjo2NDM3LCJhIjoxMjExLCJrIjoibWFya2V0In0",
  "has_more": true
}
```

The identity:

```json
{
  "account_id": "0198a6f6-82a5-7abc-9f2a-4f0fb4374941",
  "status": "ACTIVE",
  "wallet": "0x1111111111111111111111111111111111111111"
}
```

Each market is one outcome, named by `outcome_id`, with a YES and a NO side.
[Get market](/hyperliquid/api-reference/markets/get-market) returns one with its question, rules and
24h stats. `wallet` is your Totalis wallet: it signs your trades. A failed call returns the
[error envelope](/hyperliquid/errors): `UNAUTHENTICATED` means the key is missing, expired or revoked,
and `FORBIDDEN` means it lacks a scope.

## 3. Open a position

Fund your wallet with USDC on HyperEVM first (see
[Open a position](/hyperliquid/open-a-position#before-you-start)). Then open a single on the YES side of
outcome `1209` for 5 USDC:

```ts
import { createTotalis } from "@totalistrading/hip4-client";
import { privateKeyToAccount } from "viem/accounts";

const totalis = createTotalis({
  environment: "production",
  accessToken: process.env.TOTALIS_API_KEY!,
  signer: privateKeyToAccount(process.env.TOTALIS_WALLET_KEY as `0x${string}`),
});

const opened = await totalis.openPosition({
  legs: [{ outcome_id: "1209", side: "YES" }],
  stake: 5_000_000n, // 5 USDC
});
console.log(opened.status, opened.positionId); // ACCEPTED and the new position's ID

if (opened.operationId) {
  const fill = await totalis.waitForOperation(opened.operationId);
  console.log(fill.status); // COMMITTED: the position is on-chain
}
totalis.close();
```

`openPosition` creates the RFQ, waits for quotes on your account stream, accepts the best one with
your wallet's signature, and funds any shortfall from your wallet in the same accept. The raw calls,
every result and the choices you can make are on [Open a position](/hyperliquid/open-a-position).

The Hyperliquid API lives at `https://hip4-api.totalis.trade`. It is a separate API from the
[Solana API](/guides/quickstart), with its own keys.

## 1. Call the API right now

Market reads need no key and no account:

```bash
curl "https://hip4-api.totalis.trade/v1/markets?limit=3"
```

```json
{
  "items": [
    {
      "outcome_id": "1209",
      "title": "HYPE touches 100 by 20261001-0000",
      "quote_asset": "USDC",
      "state": "ACTIVE",
      "category": "crypto",
      "sides": [ ... ]
    }
  ],
  "page": {
    "catalog_generation": "5406",
    "next_cursor": "eyJnIjo1NDA2LCJhIjoxMjA5LCJrIjoibWFya2V0In0",
    "has_more": true
  }
}
```

Each market is one HIP-4 outcome, identified by `outcome_id`. Read a single one by ID with [Get market](/hyperliquid/api-reference/market-data/get-market):

```bash
curl "https://hip4-api.totalis.trade/v1/markets/1209"
```

[List questions](/hyperliquid/api-reference/market-data/list-questions) groups outcomes under their
question (for example, every club in a league winner market), and
[Search catalog](/hyperliquid/api-reference/market-data/search-catalog) finds markets by text.

Everything past this point needs a key.

## 2. Get an API key

Create a key in the [Totalis app](https://app.totalis.trade/account/api-keys), under Account, then
API keys. Grant only the scopes your integration needs. For a read-only start, `identity:read` and
`account:read` are enough. The full scope catalog is on
[Authentication](/hyperliquid/authentication).

<Warning>
Copy the key when it is shown. It is displayed exactly once and cannot be retrieved later.
</Warning>

Store it in an environment variable:

```bash
export TOTALIS_HL_API_KEY="ttk_v1_prd_..."
```

## 3. Make your first authenticated call

Send the key as a bearer token. Confirm it works by reading your identity:

```bash
curl https://hip4-api.totalis.trade/v1/me \
  -H "Authorization: Bearer $TOTALIS_HL_API_KEY"
```

```json
{
  "participant_id": "0198a6f6-82a5-7abc-9f2a-4f0fb437493e",
  "status": "ACTIVE",
  "wallets": [
    {
      "chain_id": "999",
      "address": "0x...",
      "wallet_kind": "PRIVY_EMBEDDED_EOA",
      "financial_signing_state": "QUALIFIED",
      "link_version": "1",
      "status": "LINKED",
      "eligibilities": []
    }
  ]
}
```

A `401` with `UNAUTHENTICATED` means the key is missing, malformed, expired, or revoked. A `403`
means the key is valid but lacks the scope the route requires. Every operation in the API reference
states the scopes it requires, for example [Create RFQ](/hyperliquid/api-reference/rfqs-and-quotes/create-rfq).

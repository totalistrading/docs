A `maker` subscription streams one maker: every open RFQ to quote, the acceptances of your quotes to
confirm, and your maker's operations, positions and capital. How to connect, apply events and resume is
on [Connect and resume](/hyperliquid/streams).

| | Value |
| --- | --- |
| Key | Maker key for this `maker_id`, with at least one of `rfq:read`, `quote:read`, or `vault:read` with every maker read permission |
| Resume from a cursor | Also needs `replay:read` |
| SDK | `maker.stream`, or `new TotalisStream({ subscription: { type: "maker", maker_id }, ... })` |

Each class of frame needs its own scope, and a key receives only the classes its scopes allow:

| Frames | Needs |
| --- | --- |
| RFQ frames: `open_rfqs`, `RFQ_*` | `rfq:read` |
| Acceptance frames: `acceptances`, `QUOTE_ACCEPTED` | `quote:read` |
| Maker account frames: `operations`, `OPERATION_UPDATED`, `POSITION_*`, `MAKER_CAPITAL_UPDATED`, `COLLATERAL_REDUCTION_UPDATED` | `vault:read` and the maker permissions `READ_ACTIVITY`, `READ_CAPITAL`, `READ_PERFORMANCE`, `READ_POSITIONS` |

## Subscribe frame

```json
{
  "method": "subscribe",
  "subscription": {
    "type": "maker",
    "maker_id": "7",
    "cursor": {
      "stream_id": "0199a1c2-3b4d-7e5f-8a6b-1c2d3e4f5a60",
      "generation_id": "0199a1c2-3b4d-7e5f-8a6b-1c2d3e4f5a61",
      "sequence": "184233"
    }
  }
}
```

| Field | Required | Meaning |
| --- | --- | --- |
| `type` | Yes | Always `maker`. |
| `maker_id` | Yes | The maker your key acts for. Another maker's ID closes with `SUBSCRIPTION_DENIED`. |
| `cursor` | No | Your last applied cursor, to resume after it. Omit it to start from a snapshot. |
| `account_reads` | No | `true` to receive `readInvalidated` frames when a maker read changes. |
| `publication_freshness` | No | `true` for a 1000 ms heartbeat and `publication` checkpoints. |

## Snapshot

| Class | Holds | `href` when `truncated` |
| --- | --- | --- |
| `open_rfqs` | Every open RFQ, as [Get RFQ](/hyperliquid/api-reference/rfqs/get-rfq) returns it | `/v1/rfqs`, [List RFQs](/hyperliquid/api-reference/rfqs/list-rfqs) |
| `acceptances` | Acceptances awaiting your confirm, earliest deadline first, the same items as `QUOTE_ACCEPTED` | `/v1/makers/{maker_id}/acceptances`, [List acceptances](/hyperliquid/api-reference/quotes/list-acceptances) |
| `operations` | Your maker's operations | `/v1/me/operations`, [List operations](/hyperliquid/api-reference/account/list-operations) |

```json
  "data": {
    "cursor": { "stream_id": "0199a1c2-3b4d-7e5f-8a6b-1c2d3e4f5a60", "generation_id": "0199a1c2-3b4d-7e5f-8a6b-1c2d3e4f5a61", "sequence": "184240" },
    "resources": {
      "open_rfqs": [],
      "acceptances": [],
      "operations": [
        {
          "operation_id": "0x5e5e5e5e5e5e5e5e5e5e5e5e5e5e5e5e5e5e5e5e5e5e5e5e5e5e5e5e5e5e5e5e",

```

Snapshot, truncation route and stream together reach every pending acceptance: acceptances made after
the snapshot arrive as events. Read your capital and positions over HTTP when you connect: they are not
snapshot classes.

## Events

| Event | When | Payload |
| --- | --- | --- |
| `RFQ_CREATED` | An entry or cash-out RFQ opened | The whole open RFQ, without `status`. Entry: `rfq_id`, `kind: ENTRY`, `taker`, `stake`, `legs`, `created_at`, `expires_at`. Cash-out: `rfq_id`, `kind: CASHOUT`, `position_id`, `owner`, `maker_id`, `legs`, `legs_hash`, `leg_state`, `decision_block`, `decision_read_gas`, `created_at`, `expires_at`. |
| `RFQ_ACCEPTED`, `RFQ_CANCELLED`, `RFQ_FAILED` | An RFQ had a quote accepted, was cancelled, or its trade failed on-chain. Stop quoting it. | `rfq_id`, `status`, `terminal_reason`, `created_at`, `expires_at` |
| `QUOTE_ACCEPTED` | A taker accepted your quote and awaits your confirm | `quote_id`, `rfq_id`, `kind`, `deadline`, and `entry`, `sell_back` or `transfer`. Answer on [Confirm quote](/hyperliquid/api-reference/quotes/confirm-quote) before `deadline`. The taker's signature and `acceptance_id` are never included. |
| `OPERATION_UPDATED` | One of your maker's operations changed status | `operation_id`, `kind`, `status`, `transaction_hash`, `updated_at` |
| `POSITION_OPENED`, `POSITION_TRANSFERRED`, `POSITION_SETTLED`, `POSITION_CLOSED`, `POSITION_UPDATED` | A position your maker backs changed on-chain | `position_id`, `block_number`, `log_index`. Read the position. |
| `MAKER_CAPITAL_UPDATED` | Your maker's vault capital changed on-chain | `maker_id`, `block_number`, `log_index`. Read [Get maker capital](/hyperliquid/api-reference/makers/get-maker-capital). |
| `COLLATERAL_REDUCTION_UPDATED` | A collateral reduction job changed status | `job_id`, `status`, `operation_id` (null until the job is durable), `updated_at` |

An RFQ leaves quote collection at its `expires_at`, which sends no event. Drop it yourself on the venue
clock.

Account events (`QUOTE_CREATED`, `QUOTE_REMOVED`, balance, funding and withdrawal events) never reach a
maker subscription. How to answer each event is on [Make markets](/hyperliquid/make-markets).

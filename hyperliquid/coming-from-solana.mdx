The Hyperliquid API is a separate API from the [Solana API](/guides/quickstart), with its own base
URL, keys, and flows. Three design choices explain almost every difference.

| Choice | What it means for you |
| --- | --- |
| **Totalis cannot move your funds.** On Solana, enabling trading lets Totalis sign for your wallet. On Hyperliquid, the vault contract only executes a trade, cashout, deposit, or withdrawal signed by the wallet that owns the funds. | You sign an EIP-712 or EIP-3009 message for every money movement and send the signature with your API key. See [Keys and signatures](/hyperliquid/authentication#keys-and-signatures). |
| **Writes finish on-chain, after the response.** A command is accepted once it is durably queued. | Commands return `202` with an `operation_id` or a resource to poll, instead of waiting for the result. |
| **Every command is retry-safe.** | Every command `POST` takes an `Idempotency-Key`. Resending the same key and body returns the original result. See [Idempotency](/hyperliquid/conventions#idempotency). |

## Side by side

| | Solana API | Hyperliquid API |
| --- | --- | --- |
| Base URL | `https://api.totalis.trade` | `https://hip4-api.totalis.trade` |
| Markets | Kalshi and Polymarket markets by `market_ticker` and `venue` | Hyperliquid HIP-4 outcomes by `outcome_id`, grouped into questions |
| A leg's side | `yes` or `no` | `0` (YES) or `1` (NO) |
| Singles | Not offered. Every bet is a parlay. | One leg is a single. Two or more is a parlay. |
| Amounts | Decimal USDC, such as `25` | Base-unit strings, such as `"25000000"` for 25 USDC |
| Limits | [Limits and fees](/guides/limits-and-fees) | [Limits and timing](/hyperliquid/conventions#limits-and-timing) |
| Webhooks | [Webhooks](/guides/webhooks) | None. Use the [realtime stream](/hyperliquid/api-reference/realtime/open-realtime-stream) and its replay cursors. |

## Placing a bet

| Step | Solana API | Hyperliquid API |
| --- | --- | --- |
| Ask for prices | `POST /v1/quote-requests` | `POST /v1/rfqs` |
| Watch quotes | The quote request SSE stream | [List book quotes](/hyperliquid/api-reference/rfqs-and-quotes/list-book-quotes), or `BOOK_QUOTES_CHANGED` on the stream |
| Take a quote | `POST /v1/quote-requests/{id}/commit`, which waits for the maker to confirm | Sign `TakerAccept`, then [Begin attempt](/hyperliquid/api-reference/rfqs-and-quotes/begin-attempt). Poll the attempt while the maker confirms. |
| Know it landed | The commit response | Follow the attempt's `operation_id` until it is `COMMITTED` |
| Get paid | Automatic | Automatic. Payouts land in your vault balance. |
| Cash out early | A cashout auction you accept | A cashout RFQ. Take a bid, then countersign it as the owner. |
| Move money | Totalis moves it for you | You sign each [deposit and withdrawal](/hyperliquid/funding). Totalis pays the gas. |

The full flow with code is in the [trading walkthrough](/hyperliquid/trading).

## Making markets

| | Solana API | Hyperliquid API |
| --- | --- | --- |
| Receive requests | SSE maker stream, plus a WebSocket for fills | One WebSocket, [`/v1/stream`](/hyperliquid/market-makers#4-stream-rfqs), with snapshot and replay |
| Prices to start from | Each leg carries the venue price when the request opened | None. Bring your own Hyperliquid market data. |
| Quote | `payout_odds`. Totalis derives every amount. | The full quote terms: stake, payout, fees, expiry, salt |
| Confirm a fill | `POST /v1/mm/quotes/{id}/confirm` | Sign the `Quote` with your quote signer and send it to [Confirm attempt](/hyperliquid/api-reference/rfqs-and-quotes/confirm-attempt) |
| Collateral | Wallet plus vault balance, netted across your book automatically | Your maker vault on-chain. Request relief with a [collateral reduction](/hyperliquid/api-reference/funds-and-tickets/create-collateral-reduction). |
| Identity | Your user ID | A `maker_id` owned by a controller wallet, with a separate quote signer |

The full setup is in the [market maker guide](/hyperliquid/market-makers).

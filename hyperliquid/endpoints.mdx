The API has 30 public operations on `https://hip4-api.totalis.trade`. They are grouped the way you use
them: [Trading](#trading) is the taker flow, [Market maker](#market-maker) is the maker flow, and the
rest are shared. Each page below is generated from the OpenAPI spec and lists the route's scopes, body,
responses and error codes. Terms are defined on [Glossary](/hyperliquid/glossary).

Reads marked **recovery** are only needed after a reconnect, a truncated snapshot or a lost response.

## Trading

The taker flow: request quotes, accept one to open a position, and cash a position out.

| Endpoint | Route |
| --- | --- |
| [Create RFQ](/hyperliquid/api-reference/rfqs/create-rfq) | `POST /v1/rfqs` |
| [Accept quote](/hyperliquid/api-reference/quotes/accept-quote) | `POST /v1/quotes/{quote_id}/accept` |
| [Cancel RFQ](/hyperliquid/api-reference/rfqs/cancel-rfq) | `POST /v1/rfqs/{rfq_id}/cancel` |
| [Cash out position](/hyperliquid/api-reference/positions/cash-out-position) | `POST /v1/positions/{position_id}/cashout` |
| [List RFQs](/hyperliquid/api-reference/rfqs/list-rfqs) (recovery) | `GET /v1/rfqs` |
| [Get RFQ](/hyperliquid/api-reference/rfqs/get-rfq) (recovery) | `GET /v1/rfqs/{rfq_id}` |
| [List quotes](/hyperliquid/api-reference/quotes/list-quotes) (recovery) | `GET /v1/rfqs/{rfq_id}/quotes` |
| [Get acceptance](/hyperliquid/api-reference/quotes/get-acceptance) (recovery) | `GET /v1/quotes/{quote_id}/acceptance` |

## Market maker

The maker flow: quote RFQs, cancel quotes, confirm accepted quotes, and manage capital.

| Endpoint | Route |
| --- | --- |
| [Create quote](/hyperliquid/api-reference/quotes/create-quote) | `POST /v1/rfqs/{rfq_id}/quotes` |
| [Cancel quote](/hyperliquid/api-reference/quotes/cancel-quote) | `DELETE /v1/quotes/{quote_id}` |
| [Confirm quote](/hyperliquid/api-reference/quotes/confirm-quote) | `POST /v1/quotes/{quote_id}/confirm` |
| [Get maker capital](/hyperliquid/api-reference/makers/get-maker-capital) | `GET /v1/makers/{maker_id}/capital` |
| [Create collateral reduction](/hyperliquid/api-reference/makers/create-collateral-reduction) | `POST /v1/makers/{maker_id}/collateral-reductions` |
| [Get collateral reduction](/hyperliquid/api-reference/makers/get-collateral-reduction) | `GET /v1/makers/{maker_id}/collateral-reductions/{job_id}` |
| [Submit self-funded transaction](/hyperliquid/api-reference/makers/submit-self-funded-transaction) | `POST /v1/makers/{maker_id}/operations/{operation_id}/self-funded-transaction` |
| [List acceptances](/hyperliquid/api-reference/quotes/list-acceptances) (recovery) | `GET /v1/makers/{maker_id}/acceptances` |

## Markets

HIP-4 markets: the catalog, one market with its sides, and price history. No API key needed.

| Endpoint | Route |
| --- | --- |
| [List markets](/hyperliquid/api-reference/markets/list-markets) | `GET /v1/markets` |
| [Get market](/hyperliquid/api-reference/markets/get-market) | `GET /v1/markets/{outcome_id}` |
| [Get market history](/hyperliquid/api-reference/markets/get-market-history) | `GET /v1/markets/{outcome_id}/history` |

## Positions

| Endpoint | Route |

## Withdrawals

A withdrawal of Totalis USDC to an external address, in one signed request.

| Endpoint | Route |
| --- | --- |
| [Create withdrawal](/hyperliquid/api-reference/withdrawals/create-withdrawal) | `POST /v1/withdrawals` |
| [Get withdrawal](/hyperliquid/api-reference/withdrawals/get-withdrawal) (recovery) | `GET /v1/withdrawals/{withdrawal_id}` |

## Account

The identity, balances, activity and operations of the account a key acts for.

| Endpoint | Route |
| --- | --- |
| [Get identity](/hyperliquid/api-reference/account/get-identity) | `GET /v1/me` |
| [Get balances](/hyperliquid/api-reference/account/get-balances) | `GET /v1/me/balances` |
| [List activity](/hyperliquid/api-reference/account/list-activity) | `GET /v1/me/activity` |
| [List operations](/hyperliquid/api-reference/account/list-operations) (recovery) | `GET /v1/me/operations` |
| [Get operation](/hyperliquid/api-reference/account/get-operation) (recovery) | `GET /v1/operations/{operation_id}` |

The contract deployment every signature is made against: chain, vault, fees and the USDC domain.

| Endpoint | Route |
| --- | --- |
| [Get deployment](/hyperliquid/api-reference/deployment/get-deployment) | `GET /v1/deployment` |

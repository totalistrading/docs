The API has 30 public operations on `https://hip4-api.totalis.trade`. Each page below is generated
from the OpenAPI spec and lists the route's scopes, body, responses and error codes. Terms are defined
on [Glossary](/hyperliquid/glossary).

| Caller | Meaning |
| --- | --- |
| Taker | A personal key. Opens and cashes out positions, withdraws. |
| Maker | A maker key. Quotes RFQs and confirms acceptances. |
| Anyone | No key needed. |
| Recovery | A read only needed after a reconnect, a truncated snapshot or a lost response. |

## Quotes

In flow order: a maker quotes an RFQ, the taker accepts the quote, and the maker confirms it. The
whole maker side is on [Make markets](/hyperliquid/make-markets).

| Endpoint | Route | Caller |
| --- | --- | --- |
| [Create quote](/hyperliquid/api-reference/quotes/create-quote) | `POST /v1/rfqs/{rfq_id}/quotes` | Maker |
| [Cancel quote](/hyperliquid/api-reference/quotes/cancel-quote) | `DELETE /v1/quotes/{quote_id}` | Maker |
| [List quotes](/hyperliquid/api-reference/quotes/list-quotes) | `GET /v1/rfqs/{rfq_id}/quotes` | Taker, recovery |
| [Accept quote](/hyperliquid/api-reference/quotes/accept-quote) | `POST /v1/quotes/{quote_id}/accept` | Taker |
| [Confirm quote](/hyperliquid/api-reference/quotes/confirm-quote) | `POST /v1/quotes/{quote_id}/confirm` | Maker |
| [Get acceptance](/hyperliquid/api-reference/quotes/get-acceptance) | `GET /v1/quotes/{quote_id}/acceptance` | Taker, recovery |
| [List acceptances](/hyperliquid/api-reference/quotes/list-acceptances) | `GET /v1/makers/{maker_id}/acceptances` | Maker, recovery |

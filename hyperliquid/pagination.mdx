---
title: 'Pagination'
icon: 'layer-group'
description: 'Every Hyperliquid list pages the same way: limit and cursor in, next_cursor and has_more out.'
---

Every list takes the same two query parameters and returns the same two top-level fields:

| | Field | Rule |
| --- | --- | --- |
| Query | `limit` | 1 to 200, default 50. [Get market history](/hyperliquid/api-reference/markets/get-market-history) allows up to 1,440. |
| Query | `cursor` | Omit it for the first page. Then send the previous `next_cursor` unchanged. |
| Response | `next_cursor` | Opaque. `null` exactly when `has_more` is `false`. |
| Response | `has_more` | `true` while another page exists. |

The collection keeps its own name (`items`, `quotes`, `acceptances`), and list context sits beside the
cursor, for example `catalog_generation` on the market list.

<CodeGroup>
```ts SDK
import { createClient, items, unwrap } from "@totalistrading/hip4-client";

const client = createClient("production", { accessToken: process.env.TOTALIS_API_KEY });

for await (const position of items(
  (query) => client.GET("/v1/me/positions", { params: { query: { ...query, limit: 100 } } }).then(unwrap),
  (page) => page.items,
)) {
  console.log(position.position_id, position.status);
}
```

```bash curl
curl "https://hip4-api.totalis.trade/v1/markets?limit=50&cursor=eyJnIjo2NDM3LCJhIjoxMjExLCJrIjoibWFya2V0In0"
```
</CodeGroup>

Do not parse or build cursors. A page can hold fewer than `limit` items, even none, while `has_more` is
`true`, so keep paging until it is `false`. `items` and `pages` do this.

A stream snapshot that cuts a class short names the list that holds the rest in `truncated`. Page it once
from the first page. See [Connect and resume](/hyperliquid/streams#snapshots-and-truncated).

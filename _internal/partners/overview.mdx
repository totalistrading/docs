These pages are for platforms that embed Totalis trading in their own product: a terminal, a
wallet, a sports or prediction market app. They are not listed in the public navigation. Bookmark
them and share the links with your team.

## At a glance

- Same API, two integration models. The difference is who holds the Solana signing key. Funds sit in on-chain vaults in both.
- Managed: each account gets a Totalis-managed embedded wallet and delegates signing once. Live today, fastest to ship, one account per end user.
- Headless: you hold the keys, register sub-accounts under one principal, and sign each on-chain action yourself. Built for platforms that already hold keys for their users.
- Both models quote, commit and settle the same way, and both use the same API key header.

## Choosing a model

| | Managed | Headless |
| --- | --- | --- |
| Status | Live | Preview, in active development |
| Signing key | An embedded wallet whose key lives in a secure enclave. The account delegates signing to Totalis once | Your own key, or your end users' keys |
| Accounts | One Totalis account per end user | One principal, many sub-accounts |
| Onboarding | One consent in the Totalis app per account | Fully programmatic, proof of key control |
| Signing | Totalis signs inside a secure enclave | You sign each transaction Totalis builds |
| Best for | A desk, a bot, or a small number of users | A platform that already holds keys for many users |

Pick managed if every end user can hold a Totalis account and log in once. Pick headless if your
users never touch Totalis directly and you already hold their keys through Privy, Turnkey, Fireblocks
or your own signer.

## Shared basics

- Base URL: `https://api.totalis.trade`
- Authentication: an API key in the `X-API-Key` header on every request. Keys are scoped; see [Authentication](/guides/authentication).
- Markets, quoting, fees and settlement behave exactly as the public docs describe. Start with [How parlays work](/guides/lifecycle) and [Limits and fees](/guides/limits-and-fees).
- Questions and onboarding: [founders@totalis.trade](mailto:founders@totalis.trade).

---
title: 'Create API key'
description: 'Create a new API key for your Totalis account. The full secret is returned only on this response, so save it immediately. Needs a Privy session or a key that holds keys:manage.'
openapi: 'POST /v1/api-keys'
---

<Note>
Every body field is optional: `name`, `preset` (`read_only`, `trading`, `full` or `headless`),
`scopes` (an explicit list that overrides `preset`), and `confirm_withdraw`. With neither `preset`
nor `scopes`, the key gets the `trading` preset. A key that would hold `funds:withdraw` also needs
`confirm_withdraw: true`, and no key can hold a scope its creator lacks.

Keys created here never expire. Revoke one to end it. An account can hold 10 active keys; the
eleventh returns `409` with reason `api_key_limit`.
</Note>

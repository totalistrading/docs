---
title: 'Create API key'
description: 'Create an API key for your Totalis account. The full secret is returned only in this response, so save it immediately. Needs a Privy session or a key that holds keys:manage.'
openapi: 'POST /v1/api-keys'
---

<Note>
Every body field is optional:

| Field | Meaning |
| --- | --- |
| `name` | A label for the key. |
| `preset` | `read_only`, `trading` or `full`. With neither `preset` nor `scopes`, the key gets `trading`. |
| `scopes` | An explicit scope list. Overrides `preset`. |
| `confirm_withdraw` | Must be `true` for a key that would hold `funds:withdraw`. |

No key can hold a scope its creator lacks. Keys created here never expire; revoke one to end it.
An account can hold 10 active keys. The eleventh returns `409` with reason `api_key_limit`.
</Note>

---
title: "Bid on an Exit Auction"
api: "PUT /v1/mm/cashout-requests/{id}/quote"
description: "Bid one all-in price on a user's early-exit auction."
---

Submit or replace your bid on an early-exit auction. Auctions arrive on the
[MM stream](/api-reference/quote-service-mm/stream) you already subscribe to as a
[`cashout_request`](/api-reference/quote-service-mm/stream#cashout-request) event, and are
**broadcast to every market maker** — including positions you do not back.

Bid **one all-in `price_micro`**: the micro-USDC the user receives. There is no direction field and
no fee term. The highest live bid wins and ties go to the earliest bid. Re-submitting replaces your
own bid atomically. To pass, submit nothing — there is no decline endpoint.

The auction lives about 10 seconds. For the payload, the two economic regimes (a closing exit
carries the profit fee on your side; acquiring a position does not) and their bid ceilings, see
[Early exit auctions](/guides/early-exit-auctions).

## Authentication

API key required, with the `mm:quote` scope. Pass it in the `X-API-Key` header.

```
X-API-Key: <key>
```

## Path parameters

<ParamField path="id" type="string" required>
  The cashout request ID (UUID) — `cashout_request_id` on the push.
</ParamField>

## Request body

<ParamField body="price_micro" type="integer" required>
  The all-in amount **the user receives**, in micro-USDC (`1_000_000` = $1.00). Integer, minimum
  `1`. May be below the user's stake — a losing parlay exits for less than it cost.

  Two ceilings apply, and both compare against micro-USDC. `user_stake`, `mm_risk` and
  `total_payout` arrive as **decimal** USDC on the push, so scale them by `1e6` first.

  Every bid must satisfy `price_micro <= total_payout * 1e6` (`price_above_max_payout`). If you are
  the position's current counterparty, a tighter fee-aware ceiling binds — roughly
  `user_stake * 1e6 + mm_risk * 1e6 * (1 - fee_bps/10_000)` (`price_above_buyback_bound`).
</ParamField>

<ParamField body="expires_in_ms" type="integer" default="15000">
  How long your bid stays live, in milliseconds. Range 5000-60000. A bid may outlive the auction;
  one that lapses mid-auction stops being the best bid. Nothing tells you when it lapses, so age
  bids out locally.
</ParamField>

The body is strict — an unknown field is a `400`.

## Response

Returns `201 Created` for your first bid on an auction, or `200 OK` when replacing your own.

<ResponseField name="data" type="object">
  <Expandable title="data">
    <ResponseField name="quote" type="object">
      The submitted bid.
      <Expandable title="quote">
        <ResponseField name="id" type="string">Bid UUID.</ResponseField>
        <ResponseField name="cashout_request_id" type="string">The auction this bid is for.</ResponseField>
        <ResponseField name="market_maker_id" type="string">Your market maker ID.</ResponseField>
        <ResponseField name="price_micro" type="integer">The all-in micro-USDC you bid.</ResponseField>
        <ResponseField name="valid_until" type="string">ISO 8601 timestamp when this bid expires.</ResponseField>

      </Expandable>

  </Expandable>
</ResponseField>

## Errors

| Status | `details.reason` | Description |
|--------|------------------|-------------|
| 400 | validation | Non-integer or non-positive `price_micro`, `expires_in_ms` out of range, unknown field, or malformed JSON. |
| 400 | `price_above_max_payout` | Bid exceeds the position's `total_payout`. Response carries `max_price_micro`. |
| 400 | `price_above_buyback_bound` | You back this position and the bid exceeds what your locked collateral covers after the profit fee. Skipped when the fee rate is briefly unavailable, and re-checked when the user commits. |
| 401 | `UNAUTHORIZED` | Missing or invalid API key. |
| 403 | `insufficient_scope` | Key lacks `mm:quote`. Response carries `required_scope`. |
| 404 | — | Auction unknown, or already evicted at its TTL. The ordinary "too slow" outcome, not a fault. |
| 409 | `self_quote` | You cannot bid on an exit for your own position. |
| 409 | `not_active` | The auction was committed or cancelled before your bid landed. |
| 409 | `expired` | The auction expired as your bid landed. |
| 409 | `MARKET_NEAR_CLOSE` | The underlying market is too close to close to exit. |
| 409 | `buyback_wallet_missing` | You back this position but no wallet is on record, so a closing exit cannot be built. Every bid on that position fails this way. |

<Warning>
Winning is not the same as being paid. The user is only ever filled at a price they explicitly
accepted, so a fill can fail if the book moves down between their tap and their commit. And if you
win by **acquiring** a position, your free balance is checked at that commit rather than when you
bid — an underfunded winning bid fails with `insufficient_buyer_balance`.
</Warning>

<RequestExample>
```bash curl
curl -X PUT https://api.totalis.trade/v1/mm/cashout-requests/$CASHOUT_REQUEST_ID/quote \
  -H "X-API-Key: $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"price_micro": 1990000, "expires_in_ms": 15000}'
```

```javascript JavaScript
const res = await fetch(
  `https://api.totalis.trade/v1/mm/cashout-requests/${cashoutRequestId}/quote`,
  {
    method: 'PUT',
    headers: { 'X-API-Key': API_KEY, 'Content-Type': 'application/json' },
    // price_micro is what the USER receives, all-in, in micro-USDC
    body: JSON.stringify({ price_micro: 1_990_000, expires_in_ms: 15_000 }),
  },
);
```

```python Python
import requests

requests.put(
    f'https://api.totalis.trade/v1/mm/cashout-requests/{cashout_request_id}/quote',
    headers={'X-API-Key': API_KEY},
    # price_micro is what the USER receives, all-in, in micro-USDC
    json={'price_micro': 1_990_000, 'expires_in_ms': 15_000},
)
```

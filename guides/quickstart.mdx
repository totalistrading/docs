## 1. Call the API right now

Market data needs no key and no account:

```bash
curl "https://api.totalis.trade/markets?limit=3"
```

Every market in the response carries the `ticker` and `venue` you reference when you build a parlay
leg (one outcome inside a parlay). [List markets](/api-reference/markets/list) has the filters for
category, venue, and search.

Everything past this point needs a key.

## 2. Get an API key

Create a key from the [Totalis Dashboard](https://app.totalis.trade), under account settings, then
API keys. Give it only the scopes (permissions) your integration needs. For a read-only start,
`account:read`, `positions:read`, and `balances:read` are enough. The full scope catalog is on
[Authentication](/guides/authentication).

<Frame caption="The key form in the app, shown with the Trading preset. Pick Read-only for a first key.">
  <img src="/images/app/02-api-keys.png" alt="The API Keys settings page with a key name field, permission presets, and the scope checkboxes" />
</Frame>

<Warning>
Copy the key when it is shown. It is displayed exactly once and cannot be retrieved later.
</Warning>

Store it in an environment variable:

```bash
export TOTALIS_API_KEY="api_live_..."
```

## 3. Make your first authenticated call

Every request to `https://api.totalis.trade` carries your key in the `X-API-Key` header. Confirm it
works by reading your profile:

```bash
curl https://api.totalis.trade/v1/me \
  -H "X-API-Key: $TOTALIS_API_KEY"
```

```json
{
  "data": {
    "id": "did:privy:...",
    "username": "satoshi",
    "wallet_address": "7Xy..."
  }
}
```

Every successful response wraps the resource in a `data` envelope.

| Response | Meaning |
| --- | --- |
| `200` | The key works. |
| `401` | The key is missing, invalid, or revoked. |
| `403` | The key is valid but lacks the scope for this endpoint, or does not start with `api_`. |

## 4. Read your account

Pull your balances, open positions, and stats in one call:

```bash
curl https://api.totalis.trade/v1/portfolio \
  -H "X-API-Key: $TOTALIS_API_KEY"
```

## 5. Before you can trade

Reads work as soon as your key does. Placing a parlay needs two more things:

<Steps>
  <Step title="USDC in your wallet">
    Send native Solana USDC to the address from
    [`GET /v1/wallet`](/api-reference/user/get-wallet). When you place a parlay, the stake moves
    into your on-chain vault by itself. See [Funding](/guides/funding).
  </Step>
  <Step title="Trading enabled">
    A one time consent in the app that lets Totalis sign trades on your behalf. You cannot do this
    from the REST API. Check the current state with
    [`GET /v1/wallet/delegation-status`](/api-reference/funds/delegation-status).
  </Step>
</Steps>
